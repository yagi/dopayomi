# ドパ読み（dopayomi）

日本語向けの RSVP リーダーです。RSVP（Rapid Serial Visual Presentation）は、文章を小さなまとまりに切って、画面の同じ場所に次々と映す読み方です。視線を中央の印に置いたまま、目を左右に動かさずに読めます。

英語なら単語ごとに区切れば済みますが、日本語には分かち書きがないので、どこで区切るかが読みやすさを左右します。ドパ読みは、文節を土台にして「目安の長さまでつなげる」やり方で区切ります。

## 使い方

`index.html` をブラウザで開き、書棚から本を選んで「再生」を押します。ビルドは不要です。ただし同梱の本と品詞モードの辞書は `fetch` で読むので、ファイルを直接開くのではなく、GitHub Pages などのウェブサーバー経由で開いてください。

- **Space**: 再生・停止
- **← →**: 1区切り戻る・進む（停止中）
- **↑ ↓**: 速度を変える（停止中）
- 「区切りの確認」をクリックすると、その位置から読めます。

## 書棚

青空文庫から10作品（羅生門、蜘蛛の糸、走れメロス、山月記、注文の多い料理店、夢十夜、銀河鉄道の夜、ごん狐、檸檬、科学者とあたま）を同梱しています。「本を追加」から、文章の貼り付けかテキストファイル（UTF-8 / Shift_JIS）の読み込みで本を足せます。青空文庫のテキストファイルなら、ルビ・注記・底本情報を自動で取り除きます。

読んだ位置は本ごとに覚え、次に開くとその文の頭から再開します。本文が書き換わっていたら冒頭から始めます。追加した本はブラウザの IndexedDB に、設定と読んだ位置は localStorage に保存します。どちらもサーバーには送りません。

## 見た目

設定の「見た目」で5種類から選べます。

| 名前 | 中身 |
|---|---|
| 標準 | 青灰の地に白いカード。最初の版の見た目です |
| 計器 | 瞬間露出器（RSVPのもとになった実験装置）がモチーフ。灰色の筐体に黒い表示窓、目盛り、黄色の差し色 |
| ドパ | 濃い紫の地に蛍光ピンクと水色、太いゴシック |
| 紙 | 紙の地に墨の明朝、罫線で区切る文庫本風（既定） |
| 夜 | ほぼ黒の地に文字だけが浮かぶ夜読み用 |

標準と紙は端末のライト／ダーク設定に合わせて色が変わります。ほかの3つは常に同じ色です。

## 区切り方

| 区切り方 | 中身 |
|---|---|
| 文節 | [BudouX](https://github.com/google/budoux) の文節境界を土台にします。軽く、すぐ使えます。 |
| 品詞 | [kuromoji.js](https://github.com/takuyaa/kuromoji.js) で品詞を判定して文節を作ります。より正確ですが、初回に辞書（約23MB）を読み込みます。 |
| 単語 | 単語分割の結果そのまま。区切りの癖を確かめる用です。 |
| 字数 | 意味を無視して一定の字数で切ります。比較用です。 |

文節・品詞モードでは、文節の切れ目に強さを付け、切れにくいところ（連体修飾、形式名詞の前、複合語など）から順に、目安の重さに収まるまでつなげます。重さは漢字を1、かなを0.8、英数字を0.5として数えます。句読点の後では必ず切り、1字だけの区切りは前に寄せます。

固有名詞は「ひとまとめにする語」に書くか、同じ並びが本文に3回以上出てくれば自動でまとめます。

## 表示時間

1区切りの表示時間（ミリ秒）は次の式です。

```
T = max(250, 0.85 × n × u) + p × s
```

- `u` は1字あたりの時間（60000 ÷ 毎分の字数）、`n` は句読点・括弧を除いた字数、`s` は「句読点での間」の倍率です。
- `p` は末尾が読点なら `1.25u`、句点なら `2.5u`、段落の最後なら `4u` です。

## ビルド

`budoux-ja.js`・`kuromoji.js`・`dict/` は生成物ですが、すぐ使えるようにリポジトリに入れています。作り直すときは次を実行します。

```
npm install
npm run build
```

`kuromoji.js` は、辞書を `fetch` で読む独自のローダー（`build/kuromoji-loader/Loader.js`）に差し替えてバンドルしています。辞書は配信の都合で `.gz` を置けない環境があるため、gzip のまま base64 にした `.txt` にしています。

同梱の本は `python3 build/aozora_books.py <元テキストのフォルダ>` で作ります。元テキストは [aozorahack/aozorabunko_text](https://github.com/aozorahack/aozorabunko_text) のものを使い、JIS X 0213 の外字は Unicode に置き換えています。
